
# Grande

Personal API Repository


## Authors

- [@dasteynnnn](https://github.com/dasteynnnn)


## Environment Variables

To run this project, you will need to add the following environment variables to your .env file

`PORT`

`JWT_SECRET`

`UPSTASH_REDIS_REST_URL`

`UPSTASH_REDIS_REST_TOKEN`


## Features

- JWT Authentication
- User Module
- Product Module


## Run Locally

Clone the project

```bash
  git clone https://github.com/dasteynnnn/grande.git
```

Go to the project directory

```bash
  cd grande
```

Pull `develop` branch

```bash
  git pull origin develop
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run start
```
